CERIONE · servidor de WhatsApp (Evolution API)

1. Na VM (Google Cloud, Oracle ou VPS com Ubuntu), cole este comando único:
   mkdir -p ~/cerione-whatsapp && cd ~/cerione-whatsapp && for f in instalar.sh docker-compose.yml Caddyfile LEIA-ME.txt; do curl -fsSLO https://cerioneapp.com.br/servidor/$f; done && bash instalar.sh
2. (ele instala o Docker, cria memória extra se a máquina for pequena e sobe tudo com HTTPS)
3. Copie EVOLUTION_URL e EVOLUTION_KEY que aparecem no final para os
   segredos do Supabase (Edge Functions -> Secrets).
4. No CERIONE: Configurações -> WhatsApp do laboratório -> Conectar WhatsApp.

Atualizar a Evolution:  cd ~/cerione-whatsapp && sudo docker compose pull && sudo docker compose up -d
Ver o que está acontecendo:  sudo docker compose logs -f evolution
Domínio próprio depois:  aponte whatsapp.seudominio.com.br para o IP da VM e rode
  bash instalar.sh whatsapp.seudominio.com.br   (e troque o EVOLUTION_URL no Supabase)
